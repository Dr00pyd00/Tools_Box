# Fiche raccourcis navigateur (Windows)

## Onglets

| Raccourci | Action |
|---|---|
| `Ctrl + Tab` | onglet suivant |
| `Ctrl + Shift + Tab` | onglet précédent |
| `Ctrl + 1` à `Ctrl + 8` | aller directement à l'onglet n°1, 2, 3... |
| `Ctrl + 9` | aller au dernier onglet |
| `Ctrl + T` | nouvel onglet |
| `Ctrl + W` | fermer l'onglet courant |
| `Ctrl + Shift + T` | rouvrir le dernier onglet fermé |
| `Ctrl + N` | nouvelle fenêtre |
| `Ctrl + Shift + N` | nouvelle fenêtre en navigation privée |

## Navigation / page

| Raccourci | Action |
|---|---|
| `Alt + ←` | page précédente (back) |
| `Alt + →` | page suivante (forward) |
| `F5` / `Ctrl + R` | recharger la page |
| `Ctrl + Shift + R` | recharger en ignorant le cache (hard refresh) |
| `Ctrl + L` / `F6` | placer le curseur dans la barre d'adresse |
| `Ctrl + F` | recherche dans la page |

## Dev

| Raccourci | Action |
|---|---|
| `F12` / `Ctrl + Shift + I` | ouvrir les DevTools |
| `Ctrl + Shift + J` | ouvrir la console DevTools |

## Navigation au clavier dans un formulaire (natif, sans extension)

| Touche | Action |
|---|---|
| `Tab` | élément interactif suivant |
| `Shift + Tab` | élément interactif précédent |
| `Espace` | cocher/décocher un radio ou checkbox |
| `↑` `↓` / `←` `→` | changer de sélection entre radios d'un même groupe (`name` partagé) |
| `Enter` | soumettre le formulaire (si focus sur submit) |

## Vimium — navigation façon Vim (extension)

Chrome/Edge : "Vimium" sur le Chrome Web Store.
Firefox : "Vimium-FF" sur addons.mozilla.org.

| Touche | Action |
|---|---|
| `f` | affiche des lettres sur chaque lien cliquable — taper la lettre = clic |
| `F` | pareil, mais ouvre dans un nouvel onglet |
| `j` / `k` | scroller bas/haut |
| `gg` / `G` | haut/bas de la page |
| `d` / `u` | scroller demi-page bas/haut |
| `H` / `L` | page précédente/suivante (historique) |
| `J` / `K` | onglet précédent/suivant |
| `x` | fermer l'onglet courant |
